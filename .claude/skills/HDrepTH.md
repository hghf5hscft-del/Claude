### บทที่ 1: Type และกลยุทธ์ชีวิต — 3 หน้า

**[ย่อหน้าแนะนำสำหรับผู้ใหม่]**
> "Type คือ 'รูปแบบพลังงาน' ของคุณ เป็นหัวใจของ Human Design ทั้งระบบ มี 5 ประเภท แต่ละประเภทมีวิธีใช้พลังงานและวิธีตัดสินใจที่ต่างกันโดยสิ้นเชิง Strategy คือ 'ท่าทาง' ที่ถูกออกแบบมาให้คุณใช้ชีวิต ไม่ใช่กฎเกณฑ์ แต่เป็นการทดลองที่พิสูจน์ได้จากผลลัพธ์ของชีวิตจริง"

เขียนส่วนนี้ให้ครอบคลุม:

**Type: [ระบุ]**
- ธรรมชาติพลังงานของ Type นี้ (มาจากไหน ทำงานอย่างไร ต่างจาก Type อื่นยังไง)
- สำหรับ **Manifesting Generator**: อธิบายว่า "Pure" หมายถึงอะไร — Sacral มีสี + Motor ต่อตรงถึง Throat ทำให้ "พูดแล้วลงมือได้ทันที" แต่ยังต้องรอ Response ก่อน
- สำหรับ **Generator**: พลัง Sacral ที่ไม่รู้จักหมด, ทำงานที่ใช่จะไม่เหนื่อย
- สำหรับ **Manifestor**: ไม่มี Sacral แต่มีพลัง Motor ต่อ Throat โดยตรง, อิสระสูงสุด
- สำหรับ **Projector**: ไม่มีพลัง Sacral, มีปัญญาเชิงลึกในการมองเห็นและชี้นำคนอื่น
- สำหรับ **Reflector**: ไม่มี Center ที่ Defined, เป็นกระจกสะท้อนสุขภาพของสังคม

**Strategy: [ระบุ]**
อธิบาย Strategy อย่างละเอียดพร้อมตัวอย่างชีวิตจริง 3–4 สถานการณ์:
- ความหมายแท้จริง (ไม่ใช่แค่คำแปล)
- ตัวอย่าง: ที่ทำงาน / ความสัมพันธ์ / การตัดสินใจ / การเริ่มต้นโปรเจกต์
- สิ่งที่เกิดขึ้นเมื่อ Follow Strategy vs เมื่อฝืน Strategy
- ความเข้าใจผิดที่พบบ่อยเกี่ยวกับ Strategy นี้

**Signature & Not-Self Theme**
- Signature (ความรู้สึกเมื่อชีวิตเดินถูกทาง): [ค่า] — มีลักษณะอย่างไรในชีวิตจริง
- Not-Self Theme (สัญญาณเตือนเมื่อออกนอก Design): [ค่า] — สถานการณ์ที่มักเกิด, วิธีใช้เป็น Feedback

### บทที่ 2: Inner Authority — วิธีตัดสินใจที่แท้จริง — 2.5 หน้า

**[ย่อหน้าแนะนำสำหรับผู้ใหม่]**
> "ใน Human Design สมองและความคิดไม่ใช่เครื่องมือตัดสินใจที่เชื่อถือได้ที่สุด Authority คือส่วนของร่างกาย/ความรู้สึกที่ออกแบบมาให้คุณ 'รู้' คำตอบที่ถูกต้องสำหรับตัวเอง แต่ละคนมี Authority ต่างกัน และวิธีเข้าถึงมันก็ต่างกันโดยสิ้นเชิง"

**Authority: [ระบุ]**

อธิบายทุก Authority ที่อาจพบ ให้อธิบายอย่างละเอียดเฉพาะอันที่ Chart มี โดยครอบคลุม:

- **Sacral Authority**: เสียง "อืม/อ๊ะ" ที่ผุดขึ้นทันที ก่อนสมองคิด — ตอบ Yes/No Questions เท่านั้น, เสียงนี้ไม่ซ้ำไม่รอ, วิธีฝึกฟัง Sacral
- **Emotional/Solar Plexus Authority**: อารมณ์เป็นคลื่น — ห้ามตัดสินใจตอนอารมณ์พุ่ง/ดิ่ง, "Sleep on it" คืออะไร, ช่วงเวลาที่ใช่คือเมื่อคลื่นสงบ
- **Splenic Authority**: เสียงกระซิบชั่วขณะที่ไม่เคยซ้ำ — ต้องจับให้ได้ในวินาทีแรก, เงียบมากแต่แม่นยำที่สุด
- **Ego/Heart Authority**: "ฉันอยากทำ / ฉันไม่อยากทำ" — ฟังสิ่งที่หัวใจ/อีโก้บอกตรง ๆ
- **Self/G Authority**: ทิศทางที่ตัวตนพาไป — ฟังการสนทนาของตัวเองตอนพูดเรื่องสำคัญ
- **Mental/No Inner Authority**: ต้องพูดออกมากับ "คนที่ไว้ใจได้" และฟังเสียงตัวเองพูด
- **Lunar Authority (Reflector)**: รอครบ 28 วัน พูดคุยกับหลายคน สังเกตความรู้สึกตลอดรอบ

สำหรับ Authority ของผู้ใช้ให้เพิ่ม:
- ตัวอย่างสถานการณ์ 3 อย่างที่ Authority นี้ทำงาน
- สิ่งที่ทำให้ Authority เงียบ (Conditioning จากสังคม)
- วิธีฝึกเข้าถึงในชีวิตประจำวัน
- ความแตกต่างระหว่าง Authority แท้ vs เสียงสมอง/ความกลัว

### บทที่ 3: Profile — บทบาทและภารกิจชีวิต — 3 หน้า

**[ย่อหน้าแนะนำสำหรับผู้ใหม่]**
> "Profile คือ 'บทบาท' ที่คุณถูกออกแบบมาเพื่อเล่นในชีวิตนี้ มาจากตัวเลขสองตัวที่มาจากระบบ I-Ching 64 Hexagram แต่ละ Line (1–6) มีธีมชีวิตที่ต่างกัน ตัวเลขแรกคือ Line ที่คุณ 'รู้ตัว' (Conscious) ตัวเลขที่สองคือ Line ที่ทำงานโดยอัตโนมัติ (Unconscious) โดยที่คุณไม่รู้สึกตัวเอง"

**6 Lines คืออะไร (ภาพรวมสั้น ๆ)**

| Line | ชื่อ | ธีม |
|---|---|---|
| 1 | Investigator | สร้างรากฐานความมั่นคงจากความรู้ |
| 2 | Hermit | พรสวรรค์ที่คนอื่นต้องมาเรียกออกมา |
| 3 | Martyr | เรียนรู้ผ่านการลองผิดลองถูก |
| 4 | Opportunist | มีอิทธิพลผ่านเครือข่ายคนใกล้ชิด |
| 5 | Heretic | แก้ปัญหาให้คนอื่นในภาพกว้าง |
| 6 | Role Model | เป็นต้นแบบผ่านสามช่วงชีวิต |

**Profile [X/Y] ของคุณ**
- **Line [X] (Conscious)**: ธีมที่คุณรับรู้และภาคภูมิใจในตัวเอง — อธิบายลักษณะ, พฤติกรรม, จุดแข็ง, ความท้าทาย
- **Line [Y] (Unconscious)**: ธีมที่ทำงานอัตโนมัติ คนอื่นมักเห็นในตัวคุณก่อน — อธิบายลักษณะ, วิธีที่มันส่งผลต่อชีวิต
- **ทั้งสอง Line ทำงานร่วมกันอย่างไร**: ธีมชีวิตหลักที่เกิดจากการผสม
- **ช่วงอายุสำคัญ**: (โดยเฉพาะ Line 6 — 3 ช่วงชีวิต: ~0–30 ทดลอง / ~30–50 สังเกต / ~50+ เป็นต้นแบบ)
- **ความสัมพันธ์**: คุณมีบทบาทอะไรในความสัมพันธ์ คนอื่นคาดหวังอะไรจากคุณ
- **อาชีพ**: รูปแบบงานที่ส่งเสริม Profile นี้
- **คำแนะนำ**: สิ่งที่ควรหยุดทำ + สิ่งที่ควรเริ่มทำ

### บทที่ 4: Definition — โครงสร้างพลังงาน — 1.5 หน้า

**[ย่อหน้าแนะนำสำหรับผู้ใหม่]**
> "Definition คือวิธีที่ Centers ที่ Defined (มีสี) ของคุณเชื่อมต่อกัน ถ้าทุก Center เชื่อมกันเป็นกลุ่มเดียวเรียก Single Definition ถ้าแยกออกเป็น 2 กลุ่มที่ไม่เชื่อมกันเรียก Split เป็นต้น Definition ส่งผลต่อความสมบูรณ์ในตัวเองและความต้องการคนอื่น"

**Definition: [ระบุ]**

- **Single**: พลังงานทุก Center เชื่อมเป็นกลุ่มเดียว รู้สึกสมบูรณ์ในตัวเองโดยธรรมชาติ ชาร์จพลังคนเดียวได้ดี แต่อยู่กับคนที่ใช่จะยิ่งมีชีวิตชีวา — ผลต่อความสัมพันธ์: ไม่ต้องการคนมา "เติมเต็ม" แต่เลือกความสัมพันธ์เพื่อเติบโต
- **Split**: มี 2 กลุ่มที่แยกกัน มีบางคนที่ "Bridge" ช่องว่าง ทำให้รู้สึกสมบูรณ์ — อธิบาย Bridge Gates ที่เกี่ยวข้อง, รู้สึก "สมบูรณ์" เมื่ออยู่กับคนบางประเภท
- **Triple Split**: 3 กลุ่มแยก ต้องการสังคมกว้างและหลากหลาย
- **Quadruple Split**: ซับซ้อนมากที่สุด ต้องการสภาพแวดล้อมที่หลากหลายมาก

เพิ่มเติม:
- วิธีที่ Definition ส่งผลต่อพลังงานประจำวัน
- วิธีที่ Definition ส่งผลต่อการตัดสินใจ
- คำแนะนำสำหรับสุขภาพพลังงาน (เมื่อต้องอยู่คนเดียว vs อยู่กับคนอื่น)

### บทที่ 5: Centers — ศูนย์พลัง 9 แห่ง — 4 หน้า

**[ย่อหน้าแนะนำสำหรับผู้ใหม่]**
> "ร่างกายมี 'เสาอากาศ' 9 ต้น เรียกว่า Centers แต่ละต้นมีหน้าที่ต่างกัน Centers ที่มีสี (Defined) คือพลังงานที่คงที่ เป็นส่วนของตัวตนที่แท้จริง Centers ที่ขาวหรือเปิด (Undefined/Open) คือตัวรับสัญญาณที่ดูดพลังงานจากคนรอบข้างมาขยายให้แรงขึ้น นี่คือทั้งปัญญาและกับดักในเวลาเดียวกัน"

สำหรับแต่ละ Center ทั้ง 9 แห่ง เขียนในรูปแบบนี้:

**[ชื่อ Center] — DEFINED / UNDEFINED**

*(สำหรับ DEFINED)*
```
หน้าที่: [อธิบายพลังงาน/หน้าที่ของ Center นี้]
คุณสมบัติที่มีอย่างมั่นคง: [อธิบาย 2–3 ข้อ]
ผลกระทบต่อคนรอบข้าง: [คนอื่นสัมผัส/ได้รับอะไรจากพลังนี้]
วิธีใช้ให้เต็มประสิทธิภาพ: [คำแนะนำ]
```

*(สำหรับ UNDEFINED/OPEN)*
```
หน้าที่: [อธิบายพลังงาน/หน้าที่ของ Center นี้]

กับดัก (Not-Self Pattern): [พฤติกรรมที่เกิดเมื่อรับ Conditioning]

คำถามเช็คตัวเอง: [ประโยคคำถามที่ใช้ตรวจว่านี่ใช่ตัวเองหรือ Conditioning]

```

**9 Centers ที่ต้องครอบคลุมทั้งหมด:**

1. **HEAD** — แรงดันความคิดและคำถาม | Undefined: รับแรงดันและคำถามของคนอื่น — Not-Self: คิดเรื่องที่ไม่เกี่ยวกับตัวเองเลย
2. **AJNA** — การประมวลผลและมุมมอง | Undefined: ความคิดยืดหยุ่น — Not-Self: แกล้งทำเป็นแน่ใจเพื่อเอาใจคนอื่น
3. **THROAT** — การสื่อสารและการกระทำ | Undefined: รับรูปแบบการสื่อสาร — Not-Self: พูดเพื่อดึงความสนใจ

- Adjective (ส่วนเสริม): Gate [เลข], Line [Y] — [อธิบาย]
- ภาพรวม: สิ่งที่คุณถนัดมาแต่เกิด ทำได้โดยอัตโนมัติ

**North Node (ทิศทาง): Gate [เลข] — "[ชื่อ Gate]"**
- Verb (ใจความหลัก): Gate [เลข], Line [X] — [ชื่อ Line] = [อธิบาย]

**เรื่องราวเดียวกัน:**
เชื่อม South → North เป็นประโยคเดียว: "คุณเกิดมาเป็น [South Node ธีม] และชีวิตกำลังพาคุณไปสู่ [North Node ธีม]"

### วิธีสร้างไฟล์ .docx

ใช้ Bash tool รันสคริปต์ Python ต่อไปนี้ โดยแทนที่ `REPORT_CONTENT` ด้วยเนื้อหารายงานฉบับเต็ม:

```python
import subprocess
import sys

# ติดตั้ง python-docx ถ้ายังไม่มี
subprocess.run([sys.executable, "-m", "pip", "install", "python-docx", "-q"], check=True)

from docx import Document
from docx.shared import Pt, Cm, RGBColor, Inches
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.enum.style import WD_STYLE_TYPE
from docx.oxml.ns import qn
from docx.oxml import OxmlElement
import datetime
import os

doc = Document()

# ตั้งค่าหน้ากระดาษ A4
section = doc.sections[0]
section.page_width = Cm(21)
section.page_height = Cm(29.7)
section.left_margin = Cm(2.5)
section.right_margin = Cm(2.5)
section.top_margin = Cm(2.5)
section.bottom_margin = Cm(2.5)

# ฟังก์ชันตั้งค่าฟอนต์ภาษาไทย
def set_thai_font(run, size=12, bold=False, color=None):
    run.font.name = 'TH Sarabun New'
    run.font.size = Pt(size)
    run.font.bold = bold
    if color:
        run.font.color.rgb = RGBColor(*color)
    r = run._r
    rPr = r.get_or_add_rPr()
    rFonts = OxmlElement('w:rFonts')
    rFonts.set(qn('w:ascii'), 'TH Sarabun New')
    rFonts.set(qn('w:hAnsi'), 'TH Sarabun New')
    rFonts.set(qn('w:cs'), 'TH Sarabun New')
    rPr.insert(0, rFonts)

def add_heading(doc, text, level=1):
    p = doc.add_paragraph()
    p.alignment = WD_ALIGN_PARAGRAPH.LEFT
    run = p.add_run(text)
    sizes = {1: 20, 2: 16, 3: 14, 4: 13}
    colors = {1: (31, 73, 125), 2: (54, 95, 145), 3: (79, 129, 189), 4: (0, 0, 0)}
    set_thai_font(run, size=sizes.get(level, 13), bold=True, color=colors.get(level))
    p.paragraph_format.space_before = Pt(12 if level == 1 else 8)
    p.paragraph_format.space_after = Pt(6)
    return p

def add_body(doc, text, indent=False):
    p = doc.add_paragraph()
    p.alignment = WD_ALIGN_PARAGRAPH.JUSTIFY
    run = p.add_run(text)
    set_thai_font(run, size=13)
    p.paragraph_format.space_after = Pt(4)
    if indent:
        p.paragraph_format.left_indent = Cm(1)
    return p

def add_bullet(doc, text, level=0):
    p = doc.add_paragraph(style='List Bullet')
    run = p.add_run(text)
    set_thai_font(run, size=13)
    p.paragraph_format.left_indent = Cm(1 + level * 0.5)
    p.paragraph_format.space_after = Pt(3)
    return p

def add_table(doc, headers, rows):
    table = doc.add_table(rows=1 + len(rows), cols=len(headers))
    table.style = 'Table Grid'
    # Header row
    hdr_cells = table.rows[0].cells
    for i, h in enumerate(headers):
        hdr_cells[i].text = h
        run = hdr_cells[i].paragraphs[0].runs[0]
        set_thai_font(run, size=12, bold=True)
        hdr_cells[i].paragraphs[0].alignment = WD_ALIGN_PARAGRAPH.CENTER
        # Header background color
        tc = hdr_cells[i]._tc
        tcPr = tc.get_or_add_tcPr()
        shd = OxmlElement('w:shd')
        shd.set(qn('w:fill'), '1F497D')
        shd.set(qn('w:color'), 'FFFFFF')
        shd.set(qn('w:val'), 'clear')
        tcPr.append(shd)
        run.font.color.rgb = RGBColor(255, 255, 255)
    # Data rows
    for r_idx, row_data in enumerate(rows):
        row_cells = table.rows[r_idx + 1].cells
        for c_idx, cell_text in enumerate(row_data):
            row_cells[c_idx].text = str(cell_text)
            run = row_cells[c_idx].paragraphs[0].runs[0] if row_cells[c_idx].paragraphs[0].runs else row_cells[c_idx].paragraphs[0].add_run(str(cell_text))
            set_thai_font(run, size=12)
    doc.add_paragraph()
    return table

def add_page_break(doc):
    doc.add_page_break()

def add_divider(doc):
    p = doc.add_paragraph()
    pPr = p._p.get_or_add_pPr()
    pBdr = OxmlElement('w:pBdr')
    bottom = OxmlElement('w:bottom')
    bottom.set(qn('w:val'), 'single')
    bottom.set(qn('w:sz'), '6')
    bottom.set(qn('w:space'), '1')
    bottom.set(qn('w:color'), '4472C4')
    pBdr.append(bottom)
    pPr.append(pBdr)
    return p

# =========================================================
# เนื้อหารายงาน — แทนที่ด้วยเนื้อหาจริงจากการวิเคราะห์
# โครงสร้างด้านล่างเป็นตัวอย่าง สร้างจากข้อมูลที่วิเคราะห์ได้
# =========================================================

# หน้าปก
p = doc.add_paragraph()
p.alignment = WD_ALIGN_PARAGRAPH.CENTER
run = p.add_run('Human Design Chart')
set_thai_font(run, size=28, bold=True, color=(31, 73, 125))
doc.add_paragraph()

p = doc.add_paragraph()
p.alignment = WD_ALIGN_PARAGRAPH.CENTER
run = p.add_run('การแปลผลฉบับสมบูรณ์')
set_thai_font(run, size=22, bold=True, color=(54, 95, 145))
doc.add_paragraph()

# ใส่ชื่อ/วันเกิด (แทนที่ด้วยข้อมูลจริง)
p = doc.add_paragraph()
p.alignment = WD_ALIGN_PARAGRAPH.CENTER
run = p.add_run('[ชื่อ]  •  [วันเกิด]')
set_thai_font(run, size=16)
doc.add_paragraph()

p = doc.add_paragraph()
p.alignment = WD_ALIGN_PARAGRAPH.CENTER
run = p.add_run('โครงสร้างหลัก • Variables • Shadow Chart • Quantum Data')
set_thai_font(run, size=14, color=(128, 128, 128))
doc.add_paragraph()

p = doc.add_paragraph()
p.alignment = WD_ALIGN_PARAGRAPH.CENTER
run = p.add_run(f'วันที่จัดทำ: {datetime.date.today().strftime("%d %B %Y")}')
set_thai_font(run, size=13)

add_page_break(doc)

# =========================================================
# วิธีใช้สคริปต์นี้:
# แทนที่ส่วน "เนื้อหารายงาน" ด้านบนด้วยการเรียก add_heading(),
# add_body(), add_bullet(), add_table() ตามเนื้อหาจริง
# ที่วิเคราะห์ได้จากรูป Chart
# =========================================================

# บันทึกไฟล์
name_part = '[ชื่อ]'.replace(' ', '_')
date_part = datetime.date.today().strftime('%Y%m%d')
filename = f'/tmp/HumanDesign_{name_part}_{date_part}.docx'
doc.save(filename)
print(f'SAVED:{filename}')
```

**หลังรันสคริปต์:**
1. อ่าน path ที่ print ออกมา (บรรทัดที่ขึ้นต้นด้วย `SAVED:`)
2. ใช้ `SendUserFile` tool ส่งไฟล์ .docx ให้ผู้ใช้ทันที
3. แจ้งผู้ใช้ว่า: "รายงานฉบับสมบูรณ์พร้อมแล้ว ดาวน์โหลดไฟล์ .docx ด้านบนได้เลย"

### วิธีสร้างเนื้อหาในไฟล์ .docx

| Markdown | python-docx function |
|---|---|
| `# หัวข้อใหญ่` | `add_heading(doc, "...", level=1)` |
| `## หัวข้อรอง` | `add_heading(doc, "...", level=2)` |

| ขึ้นหน้าใหม่ | `add_page_break(doc)` |

## ขั้นตอนที่ 0 — แสดงรูปและอ่านข้อมูล

แสดงทุกรูปที่ผู้ใช้ส่งมาไว้ก่อนส่วนวิเคราะห์:

```
📊 Chart ที่ใช้ในการวิเคราะห์:
[แสดงรูปภาพ]
```

### 0A — ตรวจสอบชื่อเจ้าของ Chart ก่อนเสมอ

**ทำก่อนอ่านข้อมูลอื่นทุกครั้งที่ได้รับรูปใหม่:**

1. อ่านชื่อที่ปรากฏบน Chart (มักอยู่มุมบนของรูป หรือใต้ Body Graph)
2. บันทึกชื่อที่อ่านได้ว่า `[ชื่อในรูปนี้]`
3. เปรียบเทียบกับชื่อที่ได้รับจากรูปก่อนหน้าในเซสชันนี้ (ถ้ามี):

| กรณี | การดำเนินการ |
|---|---|
| รูปแรกในเซสชัน | บันทึกชื่อนี้เป็น "ชื่ออ้างอิง" และวิเคราะห์ต่อได้ปกติ |
| ชื่อตรงกับชื่ออ้างอิง | วิเคราะห์ต่อได้ปกติ |
| **ชื่อไม่ตรงกับชื่ออ้างอิง** | **หยุดทันที — แจ้งเตือนผู้ใช้ก่อนวิเคราะห์** |
| อ่านชื่อไม่ออกจากรูป | แจ้งผู้ใช้ว่าอ่านชื่อไม่ได้ ขอให้ยืนยันว่าเป็น Chart ของใคร |

**รูปแบบแจ้งเตือนเมื่อพบชื่อไม่ตรง:**

```
⚠️ พบชื่อไม่ตรงกัน — กรุณายืนยันก่อนดำเนินการต่อ

รูปที่เพิ่งส่งมาแสดงชื่อ: [ชื่อในรูปนี้]
ชื่อที่ใช้ในการวิเคราะห์ของเซสชันนี้: [ชื่ออ้างอิง]

รูปนี้อาจเป็น Chart ของคนอื่น ซึ่งจะทำให้รายงานปะปนข้อมูล

กรุณาเลือก:
• พิมพ์ "ใช่ ใช้ได้" → จะรวมรูปนี้ในการวิเคราะห์
• พิมพ์ "ไม่ใช่ ข้ามได้" → จะข้ามรูปนี้และไม่ใช้ในรายงาน
• พิมพ์ "เปลี่ยนชื่อ" → จะอัปเดตชื่ออ้างอิงเป็น [ชื่อในรูปนี้] และวิเคราะห์จากนี้ไป
```

**อย่าวิเคราะห์รูปที่ชื่อไม่ตรงจนกว่าผู้ใช้จะยืนยัน**

3. **ถ้าข้อมูลไม่ครบ** — เขียนส่วนที่มีให้ครบ แล้วระบุชัดเจนว่า "ต้องการข้อมูล [X] เพิ่มเติม" อย่าข้ามทั้งบท
4. **ทุกบทต้องมีตัวอย่างชีวิตจริง** — ไม่ใช่แค่นิยามทางทฤษฎี
5. **ทุกบทต้องมีย่อหน้า [INTRO] สำหรับผู้ใหม่** — 2–3 ประโยคอธิบายว่าส่วนนี้คืออะไร ก่อนเข้าการวิเคราะห์ส่วนตัว

### โครงสร้างรายงาน 13 บท

#### บทที่ 1: Type และกลยุทธ์ชีวิต (ประมาณ 3 หน้า)

**[INTRO สำหรับผู้ใหม่]** Type คืออะไร, มี 5 ประเภท แต่ละอันต่างกันอย่างไร, Strategy ทำงานอย่างไร

**เนื้อหาที่ต้องมี:**
- ธรรมชาติพลังงานของ Type นี้โดยละเอียด (ไม่ใช่แค่ชื่อ)
- Strategy — ความหมายแท้จริง + ตัวอย่างในชีวิตจริง 3 สถานการณ์ (งาน / ความสัมพันธ์ / การตัดสินใจ)
- สิ่งที่เกิดเมื่อทำตาม Strategy vs ฝืน Strategy
- ความเข้าใจผิดที่พบบ่อยเกี่ยวกับ Strategy นี้
- Signature + Not-Self Theme — ลักษณะในชีวิตจริง วิธีใช้เป็น Feedback

#### บทที่ 2: Inner Authority — วิธีตัดสินใจที่แท้จริง (ประมาณ 2.5 หน้า)

**[INTRO สำหรับผู้ใหม่]** Authority คืออะไร ทำไมสมองไม่ใช่เครื่องมือตัดสินใจที่ดีที่สุด

**เนื้อหาที่ต้องมี:**
- อธิบาย Authority ที่มีอย่างละเอียด (ไม่ใช่แค่ชื่อ)
- ตัวอย่างสถานการณ์ 3 อย่างที่ Authority นี้ทำงาน
- วิธีฝึกเข้าถึง Authority ในชีวิตประจำวัน
- ความแตกต่างระหว่าง Authority แท้ vs เสียงสมอง/ความกลัว
- สิ่งที่ทำให้ Authority เงียบ (Conditioning)

#### บทที่ 3: Profile — บทบาทและภารกิจชีวิต (ประมาณ 3 หน้า)

**[INTRO สำหรับผู้ใหม่]** Profile คืออะไร 6 Lines แตกต่างกันอย่างไร ตัวเลขแรก vs ตัวเลขที่สองหมายความว่าอะไร

**เนื้อหาที่ต้องมี:**
- ตาราง 6 Lines สั้น ๆ
- Line แรก (Conscious) — ลักษณะ พฤติกรรม จุดแข็ง ความท้าทาย
- Line สอง (Unconscious) — ลักษณะ วิธีที่ทำงานในชีวิต
- สอง Line ทำงานร่วมกันอย่างไร + ธีมชีวิตหลัก
- ช่วงอายุสำคัญ (โดยเฉพาะ Line 6)
- อาชีพและความสัมพันธ์ที่ส่งเสริม Profile
- สิ่งที่ควรหยุดทำ + สิ่งที่ควรเริ่มทำ

#### บทที่ 4: Definition — โครงสร้างพลังงาน (ประมาณ 1.5 หน้า)

**[INTRO สำหรับผู้ใหม่]** Definition คืออะไร ต่างจาก Type อย่างไร ส่งผลต่อความสัมพันธ์อย่างไร

**เนื้อหาที่ต้องมี:**
- อธิบาย Definition ที่มีอย่างละเอียด
- ผลต่อพลังงานประจำวัน
- ผลต่อความสัมพันธ์ (ต้องการคนมา Bridge หรือไม่)
- คำแนะนำสุขภาพพลังงาน

#### บทที่ 5: Centers — ศูนย์พลัง 9 แห่ง (ประมาณ 4 หน้า)

**[INTRO สำหรับผู้ใหม่]** Centers คืออะไร Defined vs Undefined ต่างกันอย่างไร ทำไม Undefined ไม่ใช่ข้อเสีย

**เนื้อหาที่ต้องมี สำหรับทุก Center ทั้ง 9 แห่ง:**

*Centers Defined:*
- หน้าที่ของ Center นี้
- คุณสมบัติที่มีอย่างมั่นคง (2–3 ข้อ)
- ผลกระทบต่อคนรอบข้าง
- วิธีใช้ให้เต็มประสิทธิภาพ

*Centers Undefined/Open:*
- หน้าที่ของ Center นี้
- ปัญญาที่ได้จากการเปิด (Wisdom)
- กับดัก Not-Self Pattern — พฤติกรรมที่เกิดเมื่อ Conditioning
- ตัวอย่างชีวิตจริงที่ Not-Self ปรากฏ
- คำถามเช็คตัวเอง
- วิธีแปลง Conditioning เป็น Wisdom

#### บทที่ 6: Channels — พลังและพรสวรรค์ (ประมาณ 3 หน้า)

**[INTRO สำหรับผู้ใหม่]** Channel คืออะไร ต่างจาก Gate อย่างไร ทำไมถึงเป็น "ของขวัญตลอดชีวิต"

**เนื้อหาที่ต้องมี สำหรับทุก Channel ที่ Active:**
- ชื่อ Channel + Centers ที่เชื่อม + Circuit
- Gate A: ชื่อ, หน้าที่, ตัวอย่างในชีวิต
- Gate B: ชื่อ, หน้าที่, ตัวอย่างในชีวิต
- Channel โดยรวม: พลังงานที่ให้, คนอื่นสัมผัสอย่างไร
- เงื่อนไขที่ Channel เปิด/ปิดสวิตช์
- วิธีใช้พลังนี้ดีที่สุด (2 ข้อ)
- เงา (Shadow) ที่ต้องระวัง

#### บทที่ 7: Incarnation Cross — พันธกิจชีวิต (ประมาณ 2 หน้า)

**[INTRO สำหรับผู้ใหม่]** Incarnation Cross คืออะไร มาจาก Gates ไหน ต่างจาก Profile อย่างไร

**เนื้อหาที่ต้องมี:**
- ตาราง 4 Gates (Conscious Sun/Earth, Unconscious Sun/Earth) + ความหมายสั้น
- ความหมายของชื่อ Cross
- พันธกิจและจุดประสงค์ชีวิต
- วิธีแสดงออกซึ่ง Cross ในชีวิตประจำวัน
- Cross มักชัดขึ้นเมื่ออายุเท่าไหร่ และทำไม
- สิ่งที่ขัดขวางการแสดงออกของ Cross

#### บทที่ 8: Variables — ธรรมชาติกาย-ใจในระดับลึก (ประมาณ 3 หน้า)

**[INTRO สำหรับผู้ใหม่]** Variables คืออะไร 4 ลูกศรบอกอะไร ต่างจากส่วนอื่นอย่างไร

**เนื้อหาที่ต้องมี (ถ้ารูปมี Variables — ถ้าไม่มีให้ระบุว่าต้องการรูปเพิ่มเติม อย่าข้ามบท):**
- ตาราง Variables ทั้ง 4 ตำแหน่ง
- Determination/Digestion: ความหมาย + ตัวอย่างการกิน/ตัดสินใจ/นอน + คำแนะนำ
- Environment: สภาพแวดล้อมที่ชาร์จพลังได้ดี + ตัวอย่างสถานที่จริง + วิธีจัดชีวิต
- Perspective/View: จิตใจมองโลกอย่างไร + ตัวอย่าง + ผลต่อการทำงาน
- Motivation: แรงผลักดันแท้ + เมื่อใช้ถูกทาง vs Transferred Motivation
- Cognition vs Sense (ถ้ามี): ร่างกายรู้ vs จิตใจรู้ ต่างกันอย่างไร + ตัวอย่าง
- Orientation (ถ้ามี): Binary/Focused/Peripheral + ผลต่อชีวิต
- สูตรรวม: ประโยคสรุปที่เชื่อม Variables ทั้งหมดเข้าเป็นคำแนะนำเดียว

#### บทที่ 9: Shadow Chart — แผนที่ "เสียงในหัว" (ประมาณ 3 หน้า)

**[INTRO สำหรับผู้ใหม่]** Shadow Chart คืออะไร Not-Self Theme คืออะไร ทำไมทุกคนมีเสียงเหล่านี้และไม่ใช่สิ่งผิดปกติ

**เนื้อหาที่ต้องมี:**
- อธิบาย 2 กลุ่มเสียง: (1) เสียงจากคนอื่น (Centers Undefined), (2) เครื่องจักรตัวเองทำงานเกิน (Centers Defined)
- สำหรับทุก Center ที่ Undefined: ชื่อเสียง + Gates ที่เกี่ยวข้อง + ลักษณะ + สถานการณ์ที่เกิด + วิธีรับรู้ + วิธีรับมือ
- สำหรับ Centers Defined ที่มีเสียงรบกวน (Head, Root): อธิบายในรูปแบบเดียวกัน
- Transferred Motivation และ Transferred View (ถ้ามี Variables)
- วิธีรับมือกับทุกเสียง — กระบวนการ 4 ขั้นตอน: หยุด → ถามว่าใหม่หรือเก่า → ตั้งชื่อให้มัน → ปล่อยผ่าน

#### บทที่ 10: Quantum Data — สถิติเชิงลึก (ประมาณ 2.5 หน้า)

**[INTRO สำหรับผู้ใหม่]** Quantum Data คืออะไร ทำไมต้องนับ 26 ตำแหน่ง มีประโยชน์อย่างไร

**เนื้อหาที่ต้องมี (ต้องการ Gates ครบ 26 ตำแหน่ง — ถ้าไม่ครบให้ระบุว่าวิเคราะห์ได้บางส่วน):**
- Lines Distribution: ตาราง Line 1–6 พร้อม % และนัยสำคัญ
- วิเคราะห์ Line สูงสุดและต่ำสุด — เชื่อมกับ Profile อย่างไร
- Energy Circuits: ตาราง Circuit % + ความหมาย
- วิเคราะห์ Circuit สูงสุด — ชีวิตออกแบบมาเพื่ออะไร
- Incarnation Quarters: ตาราง Quarter % + ดาว + ธีม
- วิเคราะห์ Quarter สูงสุด (โดยเฉพาะถ้า > 40%)
- Quarter รองทำหน้าที่ "กรอง" หรือ "เสริม" Quarter หลักอย่างไร

#### บทที่ 11: Story Line — เส้นทางจาก South Node สู่ North Node (ประมาณ 1.5 หน้า)

**[INTRO สำหรับผู้ใหม่]** South Node vs North Node คืออะไร ต่างจาก Incarnation Cross อย่างไร

**เนื้อหาที่ต้องมี:**
- South Node: Gate + Line + Verb + Adjective + ภาพรวม (สิ่งที่ถนัดมาแต่เกิด)
- North Node: Gate + Line + Verb + Adjective + ภาพรวม (ทิศทางที่ชีวิตพาไป)
- เรื่องราวเดียวกัน: ประโยคเชื่อม South → North
- การเชื่อมกับ Quantum Data หรือ Channel สำคัญ (ถ้ามี)

#### บทที่ 12: Exalted & Detriment — ของขวัญและเงาใน Chart (ประมาณ 2 หน้า)

**[INTRO สำหรับผู้ใหม่]** Exalted vs Detriment คืออะไร ทำไมดาวดวงเดียวกันถึงมีสองด้าน

**เนื้อหาที่ต้องมี:**
- ฝั่ง Personality: ตาราง "ดาวของขวัญ" (Exalted) + ตาราง "ดาวเงา" (Detriment)
- ฝั่ง Design: ตาราง "ดาวของขวัญ" + ตาราง "ดาวเงา"
- ดาวที่อยู่ทั้งสองขั้ว (ถ้ามี): อธิบายเงื่อนไขที่กำหนดว่าออกมาแบบไหน + วิธีรักษาให้อยู่ฝั่ง Exalted

#### บทที่ 13: Gate พิเศษ — จุดเชื่อมที่ลึกที่สุดใน Chart (ประมาณ 1 หน้า)

**[INTRO สำหรับผู้ใหม่]** Gate พิเศษคืออะไร ทำไมบาง Gate ถึงสำคัญกว่า Gate อื่น

**เนื้อหาที่ต้องมี (เขียนเฉพาะเมื่อพบ Gate คู่ที่เชื่อมเชิงเหตุ-ผล หรือดาวที่อยู่ใกล้ขอบ Gate > 80%):**
- Gate A + Gate B: ความหมายลึก ๆ ของแต่ละ Gate
- ทำไมทั้งสองถึงทำงานเชื่อมกัน
- ตัวอย่างชีวิตจริง
- "กุญแจ" ที่ทำให้พลังนี้ทำงานได้เต็มที่

#### บทสรุป — ข้อความถึงคุณโดยตรง (1 หน้า)

เขียนในลักษณะจดหมายส่วนตัว อบอุ่น ตรงถึงผู้อ่าน:
1. แก่นของ Design นี้ในประโยคเดียว
2. จุดแข็ง 3 อย่างที่ชัดเจนที่สุดใน Chart
3. ความท้าทายหลัก + วิธีรับมือ
4. จุดเริ่มต้นแนะนำถ้าจะเริ่มทดลองใช้ชีวิตตาม Design วันนี้
5. ข้อความให้กำลังใจ

### รูปแบบ tag สำหรับเนื้อหา

ใช้ tag ต่อไปนี้ **หนึ่ง tag ต่อหนึ่งบรรทัด**:

- `[H1]` = หัวข้อบท (ขึ้นหน้าใหม่ก่อนทุกบท — ใช้ `[PAGEBREAK]` ก่อน `[H1]`)
- `[H2]` = หัวข้อรอง
- `[H3]` = หัวข้อย่อย
- `[INTRO]` = ย่อหน้าแนะนำสำหรับผู้ใหม่ (italic, สีเทา)
- `[BODY]` = ย่อหน้าปกติ (เนื้อหาหลัก)
- `[BULLET]` = รายการ • bullet
- `[SUBBULLET]` = รายการ ◦ ย่อย
- `[TABLE_HEADER]` = แถวหัวตาราง (คอลัมน์คั่นด้วย `|`)
- `[TABLE_ROW]` = แถวข้อมูลตาราง (คอลัมน์คั่นด้วย `|`)
- `[IMAGE]` = รูปภาพ (ระบุ absolute path)
- `[IMAGE_CAPTION]` = คำอธิบายรูป (ใส่ต่อจาก `[IMAGE]` ทันที)
- `[PAGEBREAK]` = ขึ้นหน้าใหม่
- บรรทัดว่าง = เว้นบรรทัด

1. เขียน Part 1 → Write tool → `/tmp/hd_p1.txt` → แจ้งว่า "✍️ เขียนส่วน 1/4 เสร็จแล้ว"

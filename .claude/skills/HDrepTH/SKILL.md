### 0A — ตรวจสอบชื่อเจ้าของ Chart ก่อนเสมอ

**ทำก่อนอ่านข้อมูลอื่นทุกครั้งที่ได้รับรูปใหม่:**

1. อ่านชื่อที่ปรากฏบน Chart (มักอยู่มุมบนของรูป หรือใต้ Body Graph)
2. บันทึกชื่อที่อ่านได้ว่า `[ชื่อในรูปนี้]`
3. เปรียบเทียบกับชื่อที่ได้รับจากรูปก่อนหน้าในเซสชันนี้ (ถ้ามี):

| กรณี | การดำเนินการ |
|---|---|
| รูปแรกในเซสชัน | บันทึกชื่อนี้เป็น "ชื่ออ้างอิง" และวิเคราะห์ต่อได้ปกติ |
| ชื่อตรงกับชื่ออ้างอิง | วิเคราะห์ต่อได้ปกติ |
| **ชื่อไม่ตรงกับชื่ออ้างอิง** | **หยุดทันที — แจ้งเตือนผู้ใช้ก่อนวิเคราะห์** |
| อ่านชื่อไม่ออกจากรูป | แจ้งผู้ใช้ว่าอ่านชื่อไม่ได้ ขอให้ยืนยันว่าเป็น Chart ของใคร |

**รูปแบบแจ้งเตือนเมื่อพบชื่อไม่ตรง:**

```
⚠️ พบชื่อไม่ตรงกัน — กรุณายืนยันก่อนดำเนินการต่อ

รูปที่เพิ่งส่งมาแสดงชื่อ: [ชื่อในรูปนี้]
ชื่อที่ใช้ในการวิเคราะห์ของเซสชันนี้: [ชื่ออ้างอิง]

รูปนี้อาจเป็น Chart ของคนอื่น ซึ่งจะทำให้รายงานปะปนข้อมูล

กรุณาเลือก:
• พิมพ์ "ใช่ ใช้ได้" → จะรวมรูปนี้ในการวิเคราะห์
• พิมพ์ "ไม่ใช่ ข้ามได้" → จะข้ามรูปนี้และไม่ใช้ในรายงาน
• พิมพ์ "เปลี่ยนชื่อ" → จะอัปเดตชื่ออ้างอิงเป็น [ชื่อในรูปนี้] และวิเคราะห์จากนี้ไป
```

**อย่าวิเคราะห์รูปที่ชื่อไม่ตรงจนกว่าผู้ใช้จะยืนยัน**

## ขั้นตอนที่ 1 — เขียนรายงานฉบับสมบูรณ์

### กฎคุณภาพที่ห้ามละเมิด

1. **ห้ามข้ามบทใด ๆ** — ทั้ง 13 บท + บทสรุป ต้องครบทุกบท ไม่มีข้อยกเว้น
2. **ห้ามย่อจนขาดเนื้อหา** — แต่ละบทต้องมีเนื้อหาครบตามที่กำหนด
3. **ถ้าข้อมูลไม่ครบ** — เขียนส่วนที่มีให้ครบ แล้วระบุชัดเจนว่า "ต้องการข้อมูล [X] เพิ่มเติม" อย่าข้ามทั้งบท
4. **ทุกบทต้องมีตัวอย่างชีวิตจริง** — อย่างน้อย 1–2 สถานการณ์ที่อ่านแล้วนึกภาพออก
5. **ทุกบทต้องมีย่อหน้า [INTRO] สำหรับผู้ใหม่** — 2 ประโยคอธิบายว่าส่วนนี้คืออะไร

### กฎภาษาและสไตล์การเขียน (บังคับทุกบท)

- **ภาษาไทยธรรมดาเป็นหลัก** — เมื่อต้องใช้คำ HD ครั้งแรก ให้อธิบายสั้น ๆ ในวงเล็บ เช่น "Authority (เสียงภายในที่ใช้ตัดสินใจ)" จากนั้นใช้คำเดิมได้เลย
- **ประโยคสั้น อ่านรอบเดียวเข้าใจ** — ไม่มีประโยคที่ต้องอ่านซ้ำ ไม่ซ้อนแนวคิดหลายอย่างในประโยคเดียว
- **เขียนเหมือนคุยกับเพื่อน** — โทนอบอุ่น ตรงไปตรงมา ไม่ใช่บทความวิชาการ
- **ไม่ซ้ำซ้อนข้ามบท** — ถ้าพูดถึง Shadow ใน Centers แล้ว ไม่ต้องอธิบายซ้ำใน Shadow Chart — แค่อ้างอิงสั้น ๆ
- **ตัวอย่างต้องเป็นชีวิตจริง** — "เช่น เมื่อเพื่อนชวนไปงาน..." ดีกว่า "ตัวอย่างเช่น สถานการณ์ทางสังคม"
- **เป้าหมายความยาว 20–25 หน้า A4** — กระชับแต่ครบ ไม่มีเนื้อหาฟุ่มเฟือย

#### บทที่ 1: Type และกลยุทธ์ชีวิต (ประมาณ 2 หน้า)

**[INTRO]** Type คืออะไร มี 5 ประเภท Strategy คืออะไรและทำไมถึงสำคัญ

**เนื้อหาที่ต้องมี:**
- ธรรมชาติพลังงานของ Type นี้ — อธิบายด้วยภาษาชีวิตประจำวัน
- Strategy — ความหมายแท้จริง + ตัวอย่าง 2 สถานการณ์ (เช่น งาน / ความสัมพันธ์)
- สิ่งที่เกิดเมื่อทำตาม Strategy (Signature) vs ฝืน (Not-Self) — เป็นตัวอย่างสั้น ๆ

#### บทที่ 2: Inner Authority — วิธีตัดสินใจที่แท้จริง (ประมาณ 1.5 หน้า)

**[INTRO]** Authority คืออะไร ทำไมการใช้สมองอย่างเดียวถึงไม่พอ

**เนื้อหาที่ต้องมี:**
- อธิบาย Authority ที่มี — รู้สึกอย่างไรเมื่อมันทำงาน
- ตัวอย่าง 2 สถานการณ์ที่ Authority นี้ช่วยในการตัดสินใจ
- วิธีฝึกเข้าถึงในชีวิตประจำวัน + สัญญาณที่บอกว่านี่ไม่ใช่ Authority จริง

#### บทที่ 3: Profile — บทบาทและภารกิจชีวิต (ประมาณ 2 หน้า)

**[INTRO]** Profile คืออะไร ตัวเลขสองตัวบอกอะไร

**เนื้อหาที่ต้องมี:**
- Line แรก (Conscious) — ลักษณะ จุดแข็ง ความท้าทาย
- Line สอง (Unconscious) — ทำงานอย่างไรในชีวิต
- ทั้งสอง Line ทำงานร่วมกันอย่างไร + ธีมชีวิตหลักในประโยคเดียว
- คำแนะนำ: สิ่งที่ควรหยุดทำ / สิ่งที่ควรเริ่มทำ

#### บทที่ 4: Definition — โครงสร้างพลังงาน (ประมาณ 1 หน้า)

**[INTRO]** Definition คืออะไร ต่างจาก Type อย่างไร

**เนื้อหาที่ต้องมี:**
- อธิบาย Definition ที่มี — หมายความว่าอะไรในชีวิตประจำวัน
- ผลต่อความสัมพันธ์และการทำงานร่วมกับคนอื่น
- คำแนะนำสั้น: จัดสภาพแวดล้อมชีวิตให้เหมาะกับ Definition นี้อย่างไร

#### บทที่ 5: Centers — ศูนย์พลัง 9 แห่ง (ประมาณ 2.5 หน้า)

**[INTRO]** Centers คืออะไร Defined vs Undefined ต่างกันอย่างไร

**เนื้อหาที่ต้องมี สำหรับทุก Center ทั้ง 9 แห่ง:**

*Centers Defined (มีสีเข้ม):*
- พลังที่มีอย่างมั่นคงคืออะไร (1–2 ข้อ)
- คนรอบข้างรู้สึกอย่างไรกับพลังนี้

*Centers Undefined/Open (ไม่มีสี):*
- กับดักที่มักเกิดเมื่อได้รับพลังจากคนอื่น (Not-Self Pattern) + ตัวอย่างสั้น
- ปัญญาที่ได้เมื่อรับรู้กับดักนี้ได้ทัน

#### บทที่ 6: Channels — พลังและพรสวรรค์ (ประมาณ 2 หน้า)

**[INTRO]** Channel คืออะไร ต่างจาก Gate อย่างไร

**เนื้อหาที่ต้องมี สำหรับทุก Channel ที่ Active:**
- ชื่อ Channel + Centers ที่เชื่อม
- พลังงานโดยรวมที่ Channel นี้ให้ + ตัวอย่างในชีวิต
- วิธีใช้พลังนี้ดีที่สุด + เงาที่ต้องระวัง

#### บทที่ 7: Incarnation Cross — พันธกิจชีวิต (ประมาณ 1.5 หน้า)

**[INTRO]** Incarnation Cross คืออะไร มาจาก Gates ไหน

**เนื้อหาที่ต้องมี:**
- ตาราง 4 Gates (Conscious Sun/Earth, Unconscious Sun/Earth) + ความหมายสั้น
- พันธกิจชีวิตคืออะไร — อธิบายในภาษาธรรมดา
- ตัวอย่างการแสดงออกซึ่ง Cross ในชีวิตจริง 1–2 สถานการณ์

#### บทที่ 8: Variables — ธรรมชาติกาย-ใจในระดับลึก (ประมาณ 2 หน้า)

**[INTRO]** Variables คืออะไร 4 ลูกศรบอกอะไร

**เนื้อหาที่ต้องมี (ถ้าไม่มีข้อมูล Variables ให้ระบุว่าต้องการรูปเพิ่มเติม อย่าข้ามบท):**
- ตาราง Variables ทั้ง 4 ตำแหน่ง
- แต่ละ Variable: ความหมาย + คำแนะนำปฏิบัติ 1–2 ข้อ (เช่น กิน-นอน-สภาพแวดล้อม-แรงจูงใจ)
- ประโยคสรุปรวม: เชื่อม Variables ทั้งหมดเป็นคำแนะนำเดียว

#### บทที่ 9: Shadow Chart — แผนที่ "เสียงในหัว" (ประมาณ 2 หน้า)

**[INTRO]** Shadow หรือ Not-Self คืออะไร ทำไมทุกคนมีเสียงเหล่านี้และไม่ใช่สิ่งผิดปกติ

**เนื้อหาที่ต้องมี:**
- สำหรับทุก Center ที่ Undefined: ชื่อเสียง + ลักษณะ + ตัวอย่างสั้น + วิธีรับมือ
  (ไม่ต้องอธิบาย Centers ซ้ำจากบทที่ 5 — แค่โฟกัสที่เสียงและวิธีรับมือ)
- วิธีรับมือทั่วไป — 3 ขั้นตอนสั้น: รู้จัก → ตั้งชื่อ → ปล่อยผ่าน

#### บทที่ 10: Quantum Data — สถิติเชิงลึก (ประมาณ 1.5 หน้า)

**[INTRO]** Quantum Data คืออะไร ทำไมตัวเลขพวกนี้ถึงบอกอะไรบางอย่างเพิ่มเติม

**เนื้อหาที่ต้องมี:**
- ตาราง Lines Distribution (Line 1–6 + %)
- ตาราง Energy Circuits (% + ความหมายสั้น)
- ตาราง Incarnation Quarters (% + ธีมสั้น)
- สรุป: 2–3 ประโยคบอกว่า Pattern รวมหมายความว่าอะไรสำหรับคนนี้

#### บทที่ 11: Story Line — เส้นทางจาก South Node สู่ North Node (ประมาณ 1 หน้า)

**[INTRO]** South Node และ North Node คืออะไร ต่างจาก Incarnation Cross อย่างไร

**เนื้อหาที่ต้องมี:**
- South Node: สิ่งที่ถนัดมาแต่เกิด (Gate + ภาพรวมสั้น)
- North Node: ทิศทางที่ชีวิตพาไป (Gate + ภาพรวมสั้น)
- ประโยคเชื่อม: "เรื่องราวชีวิตของคุณคือการเดินทางจาก... สู่..."

#### บทที่ 12: Exalted & Detriment — ของขวัญและเงาใน Chart (ประมาณ 1 หน้า)

**[INTRO]** Exalted vs Detriment คืออะไร ทำไมดาวดวงเดียวกันถึงมีสองด้าน

**เนื้อหาที่ต้องมี:**
- ตารางรวม: ดาว | ตำแหน่ง | Exalted (ด้านดี) | Detriment (ด้านเงา)
- เน้นเฉพาะดาวที่โดดเด่น 3–5 ดวง ไม่ต้องลงทุกดวง
- ดาวที่อยู่ทั้งสองขั้ว (ถ้ามี): เงื่อนไขที่กำหนดว่าออกมาแบบไหน

#### บทที่ 13: Gate พิเศษ — จุดเชื่อมที่ลึกที่สุดใน Chart (ประมาณ 0.5 หน้า)

**[INTRO]** Gate พิเศษคืออะไร ทำไมบาง Gate ถึงสำคัญกว่า Gate อื่น

**เขียนเฉพาะเมื่อพบ Gate คู่ที่เชื่อมเชิงเหตุ-ผลชัดเจน:**
- Gate คู่นั้นคืออะไร ทำไมถึงทำงานด้วยกัน
- ตัวอย่างชีวิตจริง 1 สถานการณ์

#### บทสรุป — ข้อความถึงคุณโดยตรง (1 หน้า)

เขียนในลักษณะจดหมายส่วนตัว อบอุ่น ตรงถึงผู้อ่าน:
1. แก่นของ Design นี้ในประโยคเดียว
2. จุดแข็ง 3 อย่างที่ชัดเจนที่สุดใน Chart
3. ความท้าทายหลัก + วิธีรับมือ
4. จุดเริ่มต้น 1 อย่างที่ทำได้วันนี้เลย
5. ข้อความให้กำลังใจ

### รูปแบบ tag สำหรับเนื้อหา

ใช้ tag ต่อไปนี้ **หนึ่ง tag ต่อหนึ่งบรรทัด**:

- `[H1]` = หัวข้อบท (ขึ้นหน้าใหม่ก่อนทุกบท — ใช้ `[PAGEBREAK]` ก่อน `[H1]`)
- `[H2]` = หัวข้อรอง
- `[H3]` = หัวข้อย่อย
- `[INTRO]` = ย่อหน้าแนะนำสำหรับผู้ใหม่ (italic, สีเทา)
- `[BODY]` = ย่อหน้าปกติ (เนื้อหาหลัก)
- `[BULLET]` = รายการ • bullet
- `[SUBBULLET]` = รายการ ◦ ย่อย
- `[TABLE_HEADER]` = แถวหัวตาราง (คอลัมน์คั่นด้วย `|`)
- `[TABLE_ROW]` = แถวข้อมูลตาราง (คอลัมน์คั่นด้วย `|`)
- `[IMAGE]` = รูปภาพ (ระบุ absolute path)
- `[IMAGE_CAPTION]` = คำอธิบายรูป (ใส่ต่อจาก `[IMAGE]` ทันที)
- `[PAGEBREAK]` = ขึ้นหน้าใหม่
- บรรทัดว่าง = เว้นบรรทัด
